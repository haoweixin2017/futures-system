## 页面验收步骤

1. Ctrl+F5 强刷。打开“资料采集”，检查 FU、BU 的具体指标缺口和待接入来源，再展开阶段日志。
2. 手动检查资料；固定阶段结束后即可查询已发布资料，后续 AI 完成再出现派生事实。任务完成不等于覆盖完整。
3. 打开“资料查询”，默认当前配置合约；分别选目标与直接关联品种，核对关系、发布日期、统计期间、抓取/核验时间。
4. 使用关键词与维度过滤，翻到第二页后重新查询，应回第一页。打开“历史版本”后点“查询最新”，应退出历史模式。
5. 快速切换查询条件，确认最后选择的结果保留；正文失败后应可以重新点击读取。
6. 核对 EIA：发布日期显示 UNKNOWN，统计周独立显示，作为相关市场背景，不能据此把 FU/BU 核心供需缺口标为完整。

## 剩余边界

- 数值与引文的字面核对不能完整证明指标语义；同一引文有多个数字时仍需进一步语义核验。原文、引文及未核实项保留供检查。
- 六个核心供需固定序列尚未真正接通，不能宣称供需覆盖完整。若找到其他合法稳定公开入口，应先核对真实字段、期间和发布规则再实现解析。
- 资料关联查询仍读取当前用户任务结果 JSON，未建立独立关系索引；正文列表延迟加载，关键词全文 LIKE 仍可能较慢。大规模历史积累时需根据实际查询耗时优化。
- Git 工作区原先存在较多其他修改；全局 diff 格式检查报告大量 CRLF/空白项，本次未对无关文件进行格式清理。
- 服务重启与健康结果见下方运行记录；页面视觉与真实模型补查仍由用户现场验收。
