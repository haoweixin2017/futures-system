# 2026-09-14 修复记录：副图数值图例半成品编辑导致页面崩溃

## 现象

用户报告系统"不能登录、打不开"。实际后端与登录接口均正常（`/api/v1/health` 健康，错误凭据正确返回 401），但 `frontend/index.html` 在 11:40 的"副图数值图例"改动只完成了一半，导致 `/paper` 页面脚本崩溃、白屏，登录后无法进入系统。

## 根因（三处运行时错误）

1. `subLegendMap = {};` 出现在 `let subLegendMap = {};` 声明之前（TDZ），整个 `<script>` 块启动即中断。
2. `renderSubChart()` 的完整定义被误删，但三处调用残留（指标切换 / 周期加载 / 分时加载），触发 `ReferenceError`。
3. 新增的 `updateSubIndicatorLegend(time)` 函数体是 `updateSubIndicatorLegend();` —— 无条件自递归，必然栈溢出。

## 修复内容

- 删除 `let subLegendMap` 声明前的残留赋值行。
- 从 `backups/before_sub_values_20260914.html`（11:34 备份）原样恢复 `renderSubChart()` 定义（VOL/MACD/OI/KDJ/DMI 渲染 + `subValueMap` 构建）。
- 将 `renderSubChart` 尾部写死的标题赋值改为调用 `updateSubIndicatorLegend()`；函数本体实现为：按十字线 time（缺省取最新一根）在 `subValueMap` 中取值，更新 `#sub-values` 图例为「指标名 + 数值」。

## 验收

- Node 对提取的 `<script>` 块做语法解析通过；`renderSubChart` / `updateSubIndicatorLegend` / `getSubIndicatorTitle` 定义与调用点一一对应。
- 浏览器实测（临时账号，验后已删除）：`/login` → 模拟登录 → `/paper` 正常渲染；WebSocket 已连接；副图图例 VOL 显示「成交量 553」，切换 MACD →「MACD(12,26,9) 2.34」、OI →「持仓量 37302」，图例随指标切换与十字线联动更新。
- `config/users.yaml` 字节级恢复原状（sim / live）。
