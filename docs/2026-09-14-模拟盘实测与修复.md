# 2026-09-14 模拟盘实测与修复记录

## 背景

在**真实交易时段**（14:31 白盘）对模拟盘做端到端实测：真实登录、真实行情、真实下单，
逐项核对撮合、风控、撤单与账务一致性。共发现 3 类真实缺陷，其中 2 类会导致盈亏失真。

## 实测方法

用 `sim` 账号登录运行中的服务，针对实时行情（SA2701 等）实际提交委托，覆盖：
挂单→冻结→撤单→解冻的资金闭环、风控拒绝场景、成交后账务恒等式、双向持仓、部分平仓。

## 实测通过的部分（无问题）

- **风控拒绝**：单笔超限、无持仓平仓、未知合约、非正价格（HTTP 422）均正确拦截，且**拒绝原因清晰**（如"单笔手数 51 超过风控上限 50"）。
- **资金闭环**：挂单冻结 → 撤单解冻，可用资金**精确复原**（误差 0.0000）。
- **账务恒等式**：`权益 = 余额 + 浮盈`、`可用 = 权益 - 保证金 - 冻结` 两项在实测中完全自洽。
- **止损单**：条件单触发后能正确生成平仓委托并真正平掉持仓。
- **双向持仓**：同合约多空独立核算，互不干扰。
- **保证金释放**：全部平仓后保证金与冻结均归零。

## 修复的缺陷

### 缺陷 1（严重）：一键全平被单个品种拖死

**现象**：`close_all_positions()` 遍历持仓逐个提交平仓，只要遇到一个**缺行情的品种就 `raise ValueError`**。由于该方法带 `@atomic` 事务装饰器，异常会导致**整轮事务回滚** —— 连有行情、本可以平掉的品种也一并撤销。

**实测复现**：账户持有 SA2701（有行情）+ FU2611（无行情），调用全平 → 抛 ValueError，平仓前持仓 `[SA2701, FU2611]`，平仓后**仍然** `[SA2701, FU2611]`，`close_all_positions` 后状态被回滚到调用前。

**影响**：紧急平仓是风控最后一道闸门。行情断流时恰恰最需要兜底，而旧实现会让整个平仓操作失效。这是"在最需要它的时候恰好失灵"。

**修复**（`paper_trader.py`）：
- 改为**跳过而非中断**：某品种缺行情、无可平手数、或提交被风控拒绝 → 记入 `skipped` 继续处理下一个。
- 被跳过的品种通过 `notifier` 发出 `EMERGENCY_CLOSE_PARTIAL` **告警**，不静默。
- 逐个品种的提交异常也单独 `try/except` 捕获，不影响其余持仓。

**修复后实测**：同样场景下成功提交 1 笔（SA2701），FU2611 被明确跳过并告警。同时 `routes.py` 的 `/trade/close-all` 接口新增 `unclosed_positions` 字段与 `partial` 状态，前端可明确看到哪些品种未平掉，不再误以为已全部平仓。

### 缺陷 2（严重）：撮合忽略买卖价差，盈亏被系统性高估

**现象**：撮合价一律取 `tick.last_price`，**完全不看 bid/ask**。

**实测复现**：最新价 1000、买一 999、卖一 1001 时，买开成交价记为 1000、卖平也记为 1000 —— 一来一回**盈亏为 0**。而真实交易中买开要付卖一价（1001）、卖平只能拿买一价（999），每手实亏一个价差（SA 乘数 20，即 40 元）外加手续费。

**影响**：任何来回打平或高频策略的模拟盈亏都偏乐观，"高仿真"名不副实。

**修复**（`paper_trader.py` 新增 `_resolve_fill_price()`）：
- 买单成交价 = `min(委托价, max(卖一价, 最新价))`；卖单 = `max(委托价, min(买一价, 最新价))`。
- 成交价**永不优于自己的委托价**，杜绝"最新价穿越"的白拿价格改善。
- 对手价缺失时退化为最新价（兼容行情源差异）。
- 可通过 `system.paper_fill_uses_opponent` 关闭回退旧行为。

**修复后实测**：买开成交价 1001、卖平 999，来回打平正确显示 **-40**（旧实现为 0）；挂 1000 买、行情跌到 900 时按 **901** 成交（旧实现按 900 白拿全部改善）。

### 缺陷 3（中）：完全缺失手续费模型

**现象**：全仓库搜索 `commission` / `fee` / `手续费` **无任何实现**。

**修复**：新增 `system.paper_commission_per_lot`（每手手续费，元），在 `_execute_fill` 中按成交手数扣减，计入 `balance` / `available` / `realized_pnl`。**默认 0（不收取）**，保持与原有行为一致，需要时显式开启。
