## 一、先厘清「第一根」的两种含义

`market_bar` 的 `trading_day` 是**交易日**语义，因此交易日 `20260914` 的 1m 序列
**起点不是 09:00，而是前一交易日（9/11 周五）晚 21:00 的夜盘**：

```
交易日 20260914 的 1m 序列（共 345 根）
├─ 首根      2026-09-11 21:00   ← 夜盘开盘（真正的「第一根」）
│  ...       21:00 ~ 22:59      120 根（夜盘）
├─ 09:00     2026-09-14 09:00   ← 日盘首根（用户一直关注的「9点那根」）
│  ...       09:00 ~ 15:00      225 根（日盘）
└─ 末根      2026-09-14 14:59
```

因此下面分两段核对。

## 四、判断「不太对」的具体依据

### 4.1 量级失真（核心判据）

用「首根 ÷ 当日次高分钟」这个无量纲比值来横向对比同一合约的历史正常日：

| 交易日 | 日盘 09:00 首根量 | 当日次高 | 倍数 | 判定 |
|---|---|---|---|---|
| 2026-09-10 | 11,545 | 8,537 | 1.4x | 正常 |
| 2026-09-11 | 27,639 | 18,126 | 1.5x | 正常 |
| **2026-09-14** | **162,352** | **15,802** | **10.3x** | **异常** |

正常日稳定在 1.4~1.5x（集合竞价确实会让首根偏高，但仅此幅度），
9/14 突然放大到 **10.3 倍**，远超正常波动范围。

### 4.2 视觉后果（用户观感的直接来源）

| 渲染口径 | 09:00 首根相对高度 | 其余最高柱相对高度 |
|---|---|---|
| 按源值原样渲染 | **100%**（顶满副图） | 14.8% |
| 校正后 | 23,703 | 与夜盘峰（23,948）持平，99.0% |

一根占满 100%、其余全被压到 15% —— 这正是副图 VOL「看起来不对」的直观表现。

### 4.3 总量守恒（排除「数据错乱」的可能）

- 新浪 1m 原始 9/14 **日盘合计 = 807,026**
- 系统端校正后 9/14 **日盘合计 = 807,026**（**分毫未变**）
- 校正动作只是把首根多的部分**按后续分钟量占比加权摊回**，不改总量

→ 说明**总量没坏，坏的是「量在分钟之间的分配比例」**。

### 4.4 交叉验证：新浪 5m 聚合也含该异常值

| 项 | 值 |
|---|---|
| 新浪 5m 首根（`09:05`，覆盖 09:00~09:04） | **212,882** |
| 新浪 1m 原始 `09:01~09:05` 合计 | 212,632 |
| 差 | 250（可忽略） |

→ 说明 `162,352` **已进入新浪自己的 5m 聚合**，不是 1m 接口孤立的抖动。
即源端在分钟量分配上**确实**产生了这个值，但相对次高 10.3x 明显失真。

## 六、遗留问题（本轮新发现，尚未处理）

### 6.1 校正后 1m 与 5m 区间量不再自洽

| 项 | 值 |
|---|---|
| 系统端 1m `09:00~09:04` 合计 | 84,901 |
| 新浪 5m 首根（同区间） | 212,882 |
| 差 | **127,981** |

校正后，1m 的区间合计与 5m 首根出现明显缺口。

**但需说明**：这属**既有遗留**，非本次校正引入。
5m/15m/30m/60m 由本地引擎从 tick 合成（不含集合竞价），
1m 来自新浪分钟接口（含集合竞价），二者口径本就不同 ——
在校正之前就已然不一致，只是差异的表现形式变了。

**可选处理方向**（需决策）：
1. 高阶周期改为直接从 1m 聚合，保证层级自洽；
2. 或统一「是否含集合竞价」的口径策略；
3. 或维持现状，接受 5m 与 1m 的口径差（当前状态）。

### 6.2 对账时的常见误区

**不要**直接比较 `1m 全天合计` 与 `日线 volume`：

| 项 | 值 | 说明 |
|---|---|---|
| 新浪 1m 9/14 全天合计 | 807,026 | 只含 9/14 当天（日盘 + 少量） |
| 新浪日线 9/14 v | 1,263,929 | 含完整交易日 |
| 直接相减 | 456,903 | ❌ 错误比法 |

**正确比法**：
```
交易日合计 = 夜盘(9/11) 434,177 + 日盘(9/14) 807,026 = 1,241,203
与日线 1,263,929 差 22,726（1.80%，属正常口径差）
```
